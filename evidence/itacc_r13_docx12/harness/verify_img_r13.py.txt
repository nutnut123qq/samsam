"""HARNESS r13 (MỚI, nhóm C — marketing-02.1): kiểm ĐỘC LẬP ảnh nháp bằng NGUYÊN harness r10
`evidence/itacc_r10/g3/harness/verify_image.py.txt` (chỉ đọc, không dùng hàm kiểm của sản phẩm).
r10 gọi verify_image tay với box lấy từ DB; bản này tự động hóa đúng việc đó cho runner:

  python verify_img_r13.py.txt <thư_mục_ảnh> <packshot.png> <verify_image.py.txt>

- thư mục ảnh phải có ĐÚNG 1 *.png; sha256 file → đếm dòng image_assets có file_sha256 đó (in `SHA_DB <n>`);
- box = image_assets.meta->'packshot'->'box' (x, y, w, h) của dòng đó (mọi dòng cùng ảnh cùng meta);
- in `AI_META <ai_generated> <provider>` từ meta để đối chiếu;
- rồi chạy verify_image.py.txt <png> <packshot> x y w h (in sha256_file / info_keys / chunks / alpha255 mismatch)."""
import glob
import hashlib
import os
import runpy
import sys

import psycopg

sys.stdout.reconfigure(encoding="utf-8", errors="replace")
d, pk, verifier = sys.argv[1:4]
files = glob.glob(os.path.join(d, "*.png"))
assert len(files) == 1, files
png = files[0]
h = hashlib.sha256(open(png, "rb").read()).hexdigest()
with psycopg.connect(os.environ["DATABASE_URL"], connect_timeout=5) as c:
    n = c.execute("select count(*) from image_assets where file_sha256 = %s", (h,)).fetchone()[0]
    row = c.execute("select meta from image_assets where file_sha256 = %s order by id limit 1", (h,)).fetchone()
print("SHA_DB", n, h, flush=True)
assert row, "không có dòng image_assets cho sha file"
meta = row[0]
print("AI_META", meta.get("ai_generated"), meta.get("background", {}).get("provider"), flush=True)
x, y, w, hh = meta["packshot"]["box"]
sys.argv = [verifier, png, pk, str(x), str(y), str(w), str(hh)]
runpy.run_path(verifier, run_name="__main__")
