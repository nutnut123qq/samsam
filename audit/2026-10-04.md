## Phase 3 — Verdict + Roadmap

**Deploy verdict**: mục tiêu demo/pilot ĐÃ ĐẠT (v0.1, v0.2 đóng). Production
chưa sẵn — blockers: (1) Zalo OA chưa live (owner submit — C2.0 NEEDS-INPUT);
(2) không có conversation log/handoff; (3) gate regression nhỏ (ruff + console
encoding); (4) deploy public webhook cần VPS/tunnel + signature bắt buộc.

**Việc tiếp theo (agent làm được):**
1. Vá gate regression — ruff RUF100 + scripts in tiếng Việt an toàn trên console Windows (S)
2. Conversation log jsonl: mọi inbox/outbound qua Zalo + UI — question, answer, sources, guardrail verdict, latency (S)
3. Unanswered-question log: tách câu `NO_DATA` → biết KB thiếu gì, input cho vòng crawl kế (S)
4. Eval harness `scripts/eval_qa.py`: chạy 12 câu `tests/questions.md`, report pass/fail từng câu, exit code theo ngưỡng — regression suite cho RAG (S)
5. Multi-turn context cho `answer()`/Zalo: nhớ N lượt gần nhất per user (M)
6. Dedup persistence + yêu cầu secret khi `DEPLOY=1` (vá hai lỗ vận hành nhỏ) (S)

**Việc cần owner/user quyết hoặc cung cấp:**
- C2.0: submit dev app Zalo OA/Shopee/TikTok (đang chờ — `evidence/v02_platform.md`)
- Hồ sơ công bố SKU thật → thay `claims_whitelist.json` tự trích (nâng guardrail lên mức pháp lý thật)
- Deploy webhook public: chọn VPS/tunnel, quyết định có mở live không
- Video demo chưa xem thử trên máy khác; README chưa verify máy sạch
